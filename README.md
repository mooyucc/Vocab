# Vocab Ai

你自己的单词本 📚

只学自己真正需要的词。到期复习由同一套间隔算法调度，再用 **推荐复习**、**习题**、**猜词** 三种方式练同一批词——认、用、想，各走一遍。

当前版本：**2.50** · 最低系统：**iOS 18.6+**

## 简介

Vocab Ai 不提供海量公共词库。单词来自你的课程、教材或日常阅读：输入后可由 AI 补全释义、词性、音标、例句、词根和近反义词。

真正决定「今天练什么」的，是推荐复习。闪卡、完形填空和猜词共用这一条到期队列，而不是各算各的。数据通过 SwiftData + CloudKit 本地存储，并支持 iCloud 同步。

## 开发初衷

**痛点一：词库压力过大**  
多数记单词应用附带成千上万条词库。内容虽多，却容易让人无从下手，难以坚持。

**痛点二：功能过于繁杂**  
与背单词无关的功能和页面会分散注意力，不利于专注学习。

**痛点三：缺乏针对性**  
正在学某门课或某本教材时，真正需要的是当前这批词，而不是整本词典。

**我们的方案**  
自己建词，只在该复习的时候复习；同一批到期单词，用闪卡认、用习题用、用猜词想。

## 三大核心

推荐复习决定「练哪些词」；习题和猜词决定「怎么练」。三者共用艾宾浩斯间隔，只对已「记住」的词计时，与「复习全部」互不干扰。

### 1. 推荐复习

不是把词库从头到尾再过一遍，而是按遗忘曲线只推今天该看的词。

- 仅已点「记住了」的词进入间隔；间隔只看推荐复习里的累计次数与上次时间
- 间隔：当天 → 1 天 → 3 天 → 7 天 → 15 天 → 30 天
- 学习 Tab 用闪卡过这批词：正面单词，背面释义、词性、音标、例句，支持 TTS
- 仍保留「复习全部」和「接着上次」，用来消化生词；它们不改推荐复习的计时

闪卡认完，同一批到期词还可以立刻去做题、去猜。

### 2. 习题

用今天的推荐复习词做完形填空：在句子里把词用出来，而不是只看卡片背面。

- 默认用词条例句挖空；点选备选词，再点空格填入
- 遇变形会让你选出正确形式（如 go / went）
- 可本地换一组，或消耗 1 次 AI 调用生成全新句子
- 核对后显示对错与得分；每轮最多 10 词，全部来自当天到期队列

没有例句时，用「AI 出新题」即可开练。

### 3. 猜词

字母会自动揭开。越早抢答，得分越高——在词还没完全露出来时把它想出来。

- 先看释义，字母逐个出现；点「抢答」锁定当前分数并输入整词
- 越早抢答分越高（未揭开比例折算，满分 100）；答错可再试一次
- 连击、本局得分、上次 / 最高分
- 每局最多 10 词，同样来自当天推荐复习（过短或含空格的词会跳过）

认过、用过之后，猜词把回忆压到「还没看全就说出来」。

## 其他功能

### 词库

- **单词本**：自定义名称、图标、颜色，支持置顶、排序、合并、删除
- **添加**：手动输入后 AI 补全；拍照识别（可裁剪）后批量添加
- **筛选**：按单词本、未学习、待复习、按月份
- **批量**：多选后移动或删除

### AI 用量

- 新装或升级赠送 **20 次**免费调用
- 可按次购买，每次 **100 次**，永久有效
- 消耗场景：补全单词、更新例句、习题出题、补充词根 / 近反义词
- 设置中可查看已用 / 剩余次数，支持恢复购买

### 账户与数据

- Sign in with Apple
- iCloud 同步（CloudKit）
- CSV 导入 / 导出（可按单词本选择范围）
- 支持注销账户并清除本地数据

### 设置

- **界面语言**：简体中文、繁体中文、英语、日语、法语、西班牙语、韩语
- **学习目标语言**：与界面分开；不区分简繁，供 AI 补全与发音使用
- **外观**：跟随系统 / 浅色 / 深色
- **更新词库**：一键补充或校正词根、近义词、反义词、例句

## 本地开发

1. 用 Xcode 打开 `Vocab.xcodeproj`。
2. 配置 Deepseek API Key（构建时以 xcconfig 为准）：

```bash
cp Config/Secrets.xcconfig.example Config/Secrets.xcconfig
# 编辑 Config/Secrets.xcconfig，填入 DEEPSEEK_API_KEY
```

`Config/Secrets.xcconfig` 与 `.env` 已加入 `.gitignore`，不要提交真实 Key。若同时使用 `.env`，请与 `Secrets.xcconfig` 保持同一把 Key。

3. 连接 iPhone / 模拟器后运行。相机识别需在真机上验证。

未配置 Key 时仍可编译运行；AI 相关能力会提示缺少 API Key。
