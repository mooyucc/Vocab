# Vocab

你自己的单词本 📚

## 简介

Vocab 是一款智能单词学习应用，专为 iOS 设计，帮助你高效记忆和复习单词。结合 AI 智能填充和艾宾浩斯遗忘曲线算法，让背单词变得更加轻松有趣。

## 开发初衷

在开发 Vocab 的过程中，我们深入思考了当前记单词应用存在的痛点：

**痛点一：词库压力过大**  
大多数记单词应用提供了海量的词库和字典，虽然内容丰富，但面对成千上万的单词，用户往往感到无从下手，心理压力巨大，最终难以坚持完成学习目标。

**痛点二：功能过于繁杂**  
许多应用为了追求功能全面，添加了大量与背单词无关的功能和眼花缭乱的页面设计，这些反而分散了用户的注意力，不利于集中精力进行单词学习。

**痛点三：缺乏针对性**  
用户可能正在学习某个特定的语言课程或教材，他们最迫切的需求是掌握当前课程中的单词，而不是漫无目的地背诵整个词库。

**我们的解决方案**  
Vocab 采用极简的设计理念，结合 AI 智能辅助，让用户专注于学习自己真正需要的单词。我们相信，通过减轻心理压力、聚焦学习目标，用户能够更高效地完成单词学习，真正掌握所需词汇。

## 主要功能

### 🎯 智能学习系统
- **闪卡复习**：翻转卡片式学习体验，正面显示单词，背面显示释义、词性、音标和例句
- **艾宾浩斯遗忘曲线**：基于科学记忆规律的智能复习推荐，在最佳时机提醒复习
- **多种复习模式**：支持「推荐复习」、「复习全部」和「接着上次」三种模式

### ✨ AI 智能辅助
- **AI 自动填充**：输入单词后，AI 自动生成释义、词性、音标和例句
- **AI 更新例句**：复习时可一键生成新的例句，加深理解
- **每日激励语**：AI 生成的每日学习激励，保持学习动力

### 📷 便捷添加
- **相机识别**：拍照识别单词，支持区域裁剪，批量添加
- **单词本管理**：按日期自动分组，支持自定义单词本

### 🔊 发音支持
- 内置 TTS 语音朗读，帮助掌握正确发音

### ☁️ 数据同步
- 支持 iCloud 同步，多设备数据无缝衔接

### 🌍 多语言支持
- 支持中文和英文界面

## 技术栈

- **框架**：SwiftUI + SwiftData
- **最低支持**：iOS 16.0+
- **云服务**：CloudKit
- **AI 服务**：Deepseek API
